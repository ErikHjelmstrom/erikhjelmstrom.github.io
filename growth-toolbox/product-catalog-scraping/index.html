GROWTH TOOLBOX / DATA COLLECTION

From HTML to structured data.

A Node.js web scraping exercise that transforms a multi-page ecommerce catalogue into a clean, reusable and validated CSV dataset.

Source
Books to Scrape
Output
CSV dataset
Stack
Node.js · Cheerio

01 / THE QUESTION

Can a website catalogue become analysis-ready data?

Product information is easy to read one page at a time, but difficult to compare at scale. The goal was to collect the complete catalogue and turn repeated HTML elements into one consistent data structure.

The exercise focuses on extraction, structure and data quality rather than commercial findings.

02 / RESULT

1,000 products collected
50 categories represented
0 validation errors

03 / THE METHOD

From catalogue pages to one dataset.

  1. 01

    Map the catalogue

    Visit every catalogue page and collect each unique product URL.

  2. 02

    Extract the fields

    Open every product page and read the selected information from its HTML structure.

  3. 03

    Structure the data

    Convert the values into consistent rows and export them as a UTF-8 CSV file.

  4. 04

    Validate the output

    Check completeness, unique identifiers, prices, ratings and product URLs.

04 / THE DATASET

Seven fields.
One reusable file.

Each row represents one product and retains its source URL for traceability.

05 / VALIDATION

Collection is only useful when it can be checked.

A separate validation script tested the final CSV before publication.

  • 1,000 of 1,000 expected products found
  • 1,000 unique UPC identifiers
  • No duplicate identifiers
  • No missing required fields
  • No invalid prices, ratings or URLs

Validation passed

06 / SOURCE & LIMITATIONS

A technical exercise, not a market study.

The source is Books to Scrape ↗ , a demo ecommerce website created specifically for practising web scraping.

The source states that prices and ratings are randomly assigned. They cannot support claims about real demand, customers or the book market.

The scraper also depends on the source website’s current HTML structure. If that structure changes, the extraction selectors may need to be updated.
